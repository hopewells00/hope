# آرشیو کانال

این ربات برای آرشیو کانال‌هایی است که حساب کاربری شما اجازهٔ دسترسی به آن‌ها
را دارد. خروجی شامل یک فایل ZIP رمزدار است که `index.html` و رسانه‌های خروجی
را در خود دارد.

## راه‌اندازی

1. مقادیر محیطی موجود در نسخهٔ قبلی را تنظیم کنید:
   `BOT_TOKEN`, `ADMIN_ID`, `API_ID`, `API_HASH`, `SESSION_STRING`,
   `ZIP_PASS`, `CRYPT_PASS`.
2. برای قابلیت پیامک، متغیرهای `SMS_API_KEY`, `SMS_LINE_NUMBER` و
   `TARGET_PHONE` لازم است.
3. `pip install -r requirements.txt`
4. `supervisord -c supervisord.conf -n`

اطلاعات پایدار در پوشهٔ `data/` ذخیره می‌شود. این پوشه را در دیسک دائمی نگه
دارید تا فهرست کانال‌ها و کش آواتارها بعد از ری‌استارت باقی بماند.

## دستورهای بله

- `/start` — نمایش کانال‌ها برای انتخاب؛ اطلاعات ذخیره‌شده استفاده می‌شود.
- `/list` — فقط نام کانال‌ها، بدون عکس.
- `/refresh` — همگام‌سازی فهرست کانال‌ها و آواتارهای تغییرکرده.
- `/export all --count 30` — خروجی چند کانال در یک ZIP.
- `/export ChannelA ChannelB --days 3` — فقط پیام‌های سه روز اخیر.
- `/export all --type photos` یا `--type text` — فقط عکس یا فقط متن.
- `/w` — بلافاصله ۲۰ پیام آخر تمام کانال‌ها را می‌گیرد؛ فایل‌های بالای
  ۳۰ مگابایت حذف می‌شوند و نتیجه برای تأیید ارسال می‌شود. بعد از آن هر ۱۲
  ساعت یک خروجی خودکار می‌سازد.
- `/woff` — واچ و jobهای صف را متوقف می‌کند.
- `/y` یا `y` — تأیید؛ سپس پیامک ارسال و همان متن دوباره در بله فرستاده می‌شود.
- `/n` یا `n` — رد؛ پیامک ارسال نمی‌شود.

در صف فقط یک export هم‌زمان پردازش می‌شود تا دو درخواست روی فایل‌های موقت
یکدیگر اثر نگذارند. دانلود رسانه‌های هر export به‌صورت هم‌زمان و محدودشده با
`MEDIA_CONCURRENCY` انجام می‌شود. برای جلوگیری از کاهش یکی‌یکی پیام‌ها، پیدا
کردن تعداد مناسب با جست‌وجوی دودویی انجام می‌شود.
