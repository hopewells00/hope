# آرشیو کانال

این ربات برای آرشیو کانال‌هایی است که حساب کاربری شما اجازهٔ دسترسی به آن‌ها
را دارد. خروجی شامل یک ZIP رمزدار است که `index.html` و رسانه‌های خروجی را
در خود دارد.

## راه‌اندازی

1. متغیرهای محیطی زیر را تنظیم کنید:
   `BOT_TOKEN`, `ADMIN_ID`, `API_ID`, `API_HASH`, `SESSION_STRING`,
   `ZIP_PASS`, `CRYPT_PASS`.
2. برای قابلیت پیامک، `SMS_API_KEY`, `SMS_LINE_NUMBER` و `TARGET_PHONE` لازم
   است.
3. `pip install -r requirements.txt`
4. `supervisord -c supervisord.conf -n`

اطلاعات پایدار در پوشهٔ `data/` ذخیره می‌شود. این پوشه را روی دیسک دائمی نگه
دارید تا فهرست کانال‌ها، بک‌آپ state و کش آواتارها بعد از ری‌استارت یا ریست
دیسک باقی بماند. بک‌آپ‌های چرخشی state در `data/backups/` ذخیره می‌شوند؛ برای
دیسک جداگانه، `STATE_BACKUP_DIR` را تنظیم کنید.

اگر `DATA_DIR` تنظیم نشده باشد، پوشهٔ `data/` کنار فایل `main.py` ساخته می‌شود.
برای دیسک دائمی دیگر می‌توانید `DATA_DIR` را به یک مسیر مطلق تنظیم کنید.

## دستورهای بله

- `/start` — انتخاب هم‌زمان یک یا چند کانال با دکمه‌های انتخاب.
- `/list` — نمایش فهرست کانال‌های ذخیره‌شده.
- `/refresh` — همگام‌سازی فهرست کانال‌ها و حذف آواتار کانال‌های ترک‌شده.
- `/help` — نمایش فهرست دستورها و نمونهٔ استفاده.
- `/status` — نمایش وضعیت واچ، فاصلهٔ زمان‌بندی، کانال‌های فعلی و صف export.
- `/export all --count 30` — خروجی چند کانال در یک ZIP.
- `/export ChannelA ChannelB --days 3` — فقط پیام‌های سه روز اخیر.
- `/export all --type photos` یا `--type text` — فقط عکس یا فقط متن.
- `/export all --media-max 30M` — ردکردن رسانه‌های بزرگ‌تر از سقف مشخص‌شده.
  این محدودیت برای export عادی هم اعمال می‌شود.
- `/setlimit 100` — تنظیم سقف ZIP برحسب مگابایت؛ بات بلافاصله پیام تأیید می‌دهد.
- `/w` — اجرای فوری واچ و فعال‌کردن اجرای خودکار.
- `/w 6h`، `/w 30m` یا `/w 1d` — فعال‌کردن واچ با فاصلهٔ دلخواه.
- `/woff` — توقف واچ و لغو exportهای در صف.
- `/Add 12345` — اضافه‌کردن کاربر مجاز و ذخیره‌کردن آن در state.
- `/y` یا `y` — تأیید ارسال پیامک.
- `/n` یا `n` — رد ارسال پیامک.

سقف پیش‌فرض رسانه از `MAX_MEDIA_BYTES` می‌آید و اگر تنظیم نشده باشد
۳۰ مگابایت است. مقدارهایی مثل `30M`، `1.5GB` و تعداد بایت مستقیم قابل استفاده
هستند.

در پیام پیشرفت export دکمهٔ «لغو export» وجود دارد و فقط همان درخواست را
متوقف می‌کند. پیام‌های موقت و حساس، از جمله پیام تأیید، لینک رمز‌شده، پرسش
تعداد پیام، خطای کانال و پیام پیشرفت، بر اساس زمان ایجاد و پس از ۴ ساعت حذف
می‌شوند؛ job حذف هر دقیقه اجرا می‌شود تا پیام زودتر از موعد پاک نشود.

زمان پیام‌ها در `index.html` به وقت تهران نمایش داده می‌شود. خروجی HTML جدید
جست‌وجوی متن و نام کانال، فیلتر متن/عکس/ویدئو، شمارندهٔ زنده، نمایش بهتر رسانه‌ها،
بزرگ‌نمایی تصویر و طراحی واکنش‌گرا برای موبایل دارد.

## چرخش لاگ

`bot.log` و `bot-error.log` با `RotatingFileHandler` مدیریت می‌شوند. مقدار
پیش‌فرض حداکثر هر فایل ۱۰ مگابایت و ۵ فایل پشتیبان است:

- `LOG_MAX_BYTES`
- `LOG_BACKUP_COUNT`

Supervisor عمداً stdout/stderr را به فایل جداگانه نمی‌نویسد تا با چرخش داخلی
پایتون تداخل ایجاد نشود.

## صف export

در صف فقط یک export هم‌زمان پردازش می‌شود تا دو درخواست روی فایل‌های موقت
یکدیگر اثر نگذارند. دانلود رسانه‌های هر export به‌صورت هم‌زمان و محدودشده با
`MEDIA_CONCURRENCY` انجام می‌شود. برای جلوگیری از کاهش یکی‌یکی پیام‌ها، پیدا
کردن تعداد مناسب با جست‌وجوی دودویی انجام می‌شود.
