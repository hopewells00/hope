# ربات مدیریت کانال بله (Bale Channel Manager Bot)

ربات مدیریت کانال‌های **پیام‌رسان بله** برای export پیام‌ها به HTML و ZIP رمزدار.

## ویژگی‌ها

- 📢 مدیریت چندین کانال بله
- 📥 دریافت آخرین پیام‌ها (با رسانه) از کانال‌ها
- 🌐 ساخت فایل HTML با دیزاین مشابه تلگرام
- 🖼️ پشتیبانی از عکس، ویدیو، صدا، فایل، استیکر
- 🗜️ فشرده‌سازی در ZIP رمزدار AES-256
- ☁️ آپلود خودکار به imgurl.ir
- 🔐 رمزگذاری لینک با الگوریتم AES-256-GCM
- 📱 ارسال لینک رمزشده از طریق پیامک (sms.ir)

## تنظیمات Environment Variables

| متغیر | توضیح | ضروری |
|-------|-------|-------|
| `BOT_TOKEN` | توکن ربات بله از BotFather | ✅ |
| `ADMIN_ID` | شناسه عددی ادمین | ✅ |
| `ZIP_PASS` | رمز ZIP | ✅ |
| `CRYPT_PASS` | رمز رمزگذاری | ✅ |
| `SMS_API_KEY` | کلید API سرویس sms.ir | ✅ |
| `SMS_LINE_NUMBER` | خط پیامک | ✅ |
| `TARGET_PHONE` | شماره مقصد پیامک | ✅ |
| `MESSAGE_COUNT` | تعداد پیام (پیش‌فرض: 30) | ❌ |
| `MAX_ZIP_MB` | حداکثر حجم ZIP (پیش‌فرض: 50) | ❌ |
| `IMGURL_SESSION` | کوکی imgurl.ir | ❌ |

## نحوه استفاده

### افزودن کانال (خودکار)
ربات را به کانال اضافه کن و ادمین کن — کانال خودکار ثبت می‌شود.

### افزودن کانال (دستی)
```
/addchannel @username
/addchannel -1001234567890
```

### دستورات ربات
- `/start` — نمایش راهنما
- `/channels` — لیست کانال‌ها و انتخاب برای export
- `/addchannel` — افزودن کانال

### فرآیند Export
1. دستور `/channels` را بزن
2. با دکمه‌های ◀️ ▶️ کانال مورد نظر را انتخاب کن
3. دکمه **✅ تایید** را بزن
4. ربات پیام‌ها را دانلود و HTML+ZIP می‌سازد
5. ZIP آپلود و لینک رمزشده از طریق پیامک ارسال می‌شود

## ساختار فایل HTML خروجی

```
export.zip (رمزدار)
├── index.html      ← صفحه اصلی
└── media/          ← فایل‌های رسانه
    ├── avatar.jpg
    ├── media_0.jpg
    ├── media_1.mp4
    └── ...
```

## تفاوت با نسخه تلگرام

| قابلیت | تلگرام (قبلی) | بله (جدید) |
|--------|-----------|--------|
| پروتکل | MTProto (Telethon) | Bot API |
| احراز هویت | Session String | Bot Token |
| دسترسی کانال | اکانت کاربری | ربات ادمین |
| کتابخانه | python-telegram-bot + telethon | python-telegram-bot |

## نکات مهم

- ربات باید **ادمین** کانال باشد تا به پیام‌ها دسترسی داشته باشد
- API بله با Bot API تلگرام سازگار است
- فایل‌های کانال در پوشه `media/` ذخیره می‌شوند و HTML به صورت نسبی به آن‌ها ارجاع می‌دهد
